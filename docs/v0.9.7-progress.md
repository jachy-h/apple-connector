### TCC 环境说明

- 当前 agent 通过 SSH 运行，macOS 将 `sshd-keygen-wrapper` 视为 responsible process，明确禁止弹出 Reminders 授权（`Policy disallows prompt ...`）。
- 授权与 opt-in 测试改为通过本机 Terminal 执行。Terminal 获得持久 Reminders 权限后，`permissions.request` 返回 `reminders: full_access`，`reminders.listLists` 成功列出 `Inbox` 与 `Agents`。
- 这是宿主 TCC 归属行为，不是 v0.9.7 代码问题。后续涉及 TCC 的测试应继续从本机 Terminal 或已授权的 GUI 会话运行。
