## 本轮变更与验证

- 版本更新至 0.7.0。能力声明将 Notes 标为 `unavailable` 且不声明操作；MCP 不注册 Notes 工具，管理页不展示 Notes，CLI 容器发现仅访问 Reminders。
- 服务端对旧 Notes RPC、Notes 变更计划和历史 Notes 操作执行请求返回 `unsupported_operation`，并在进入授权、reader、writer 或 JXA 前拦截。旧授权、审计和操作元数据继续可读取。
- 新建或更新客户端时拒绝 Notes 授权；固定容器发现脚本不再启动 Notes 自动化。
- 已通过 `npx tsc -p tsconfig.json`、`node --test dist/tests/*.test.js`（73/73）、`npm run check:jxa` 与 `git diff --check`。未运行真实 Notes 诊断。
- `npm run build` 的 Web 与 TypeScript 阶段成功；Swift 原生阶段因主机 SDK 为 Swift 6.3.2、编译器为 6.3.3 且沙箱无法写入 clang module cache 而失败。
