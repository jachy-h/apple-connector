# Apple Connector v0.6.1 计划：提醒事项变更修复

更新日期：2026-09-07  
进度记录：[v0.6.1-progress.md](./v0.6.1-progress.md)

## 目标

修复提醒事项列表中编辑、删除点击后不生效的问题，并增加单条“完成”快捷操作。

## 根因与实施范围

- 当前启动流程发现后台服务仍在运行时直接复用，没有比较正在运行的服务版本。升级页面和 RPC 后仍可能连接旧服务，导致新编辑/删除方法被拒绝。
- 页面写入辅助函数吞掉请求错误并继续刷新列表，用户无法看见失败原因，也无法保留编辑内容重试。
- v0.6.1 将让启动流程读取运行服务的版本；版本不一致时正常停止旧进程并加载新构建。
- 编辑、完成、删除统一检查持久化操作回执；只有 `succeeded` 才刷新列表，确定失败显示原因，结果未知明确提示去提醒事项 App 核验且不自动重放。
- “完成”复用受核验的单条更新动作，只把当前提醒的完成状态改为 true；已完成项目不重复提交。

## 验收

1. Web 管理 RPC 的编辑、删除和完成请求均覆盖到路由、幂等状态、审计和原生 provider 调用。
2. 失败时编辑面板保留，不把失败伪装成成功；删除失败不从页面乐观移除。
3. 新版本 CLI 面对旧后台版本会重启，面对同版本后台仍保持幂等复用。
4. Web/TypeScript、Swift release 构建及完整测试通过。
