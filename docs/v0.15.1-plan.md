# Apple Connector v0.15.1 计划：彻底移除日历“字段/仅忙碌状态”

更新日期：2026-11-18

状态：已批准并实施完成（2026-11-18）；全量验证受并发 v0.16.0 未完成测试影响

进度：[v0.15.1-progress.md](./v0.15.1-progress.md)

## 结论

移除日历授权中的 `fields`（`full` / `busy`）概念，包括界面选择、策略 schema、读取投影、CLI 展示、默认配置、文档和测试。

维护者已确认：

- 完全移除“日历字段”的选择；
- **不做兼容**，不保留 `fields` 字段、不做数据迁移；
- 当前没有历史授权数据，旧 store 不作为受支持输入。

移除后：

- 新建授权不再选择字段，日历授权一律返回完整事件内容；
- `busy` 强制只读的规则一并删除；
- 授权 JSON 不再包含 `fields`；
- `calendar.list_events` 不再脱敏；
- CLI `auth show` 不再输出 `Fields`；
- 授权详情不再显示“字段”。

版本建议：`0.15.1`。授权 JSON、`auth.describe`、CLI 人类可读输出发生变化，属于破坏性变更。

## 行为变化

| 位置 | 现在 | 之后 |
| --- | --- | --- |
| 新建授权表单 | 日历容器可选择“完整内容/仅忙碌状态” | 无字段选择，只有操作勾选 |
| 日历读取 | `busy` 只返回 `start`/`end`/`allDay`/`timeZone` | 始终返回完整事件 |
| 授权 JSON | 每条 grant 含 `fields` | 不含 `fields`，多出该字段会被 schema 拒绝 |
| 授权详情 | 显示“字段：完整内容/仅忙碌状态” | 不显示字段行 |
| CLI `auth show` | 每条 grant 输出 `Fields` | 不输出 |
| 默认 Agent 配置 | grants 含 `fields: 'full'` | 不含 |

## 实施清单

### 策略与读取

- `src/policy/schema.ts`
  - 从 `grantSchema` 删除 `fields`；保留 `.strict()`，使带 `fields` 的输入被明确拒绝。
  - 删除 `superRefine` 中 busy 只能日历只读的校验；保留 Notes 只读校验。
- `src/policy/authorize.ts`
  - `authorize()` 不再合并/注入 `fields`，只返回命中的 grant（容器、动作、最早过期时间）。
  - 删除 `projectCalendarEvent()` 及其注释。
- `src/transports/local/handlers.ts`
  - `calendar.list_events` 直接返回 `page.items`，删除投影调用和 import。

### Web 管理页

- `src/web/management-view.ts`
  - `ProfileGrant`、`ContainerPermission`、`ContainerSelection` 删除 `fields`。
  - `defaultContainerPermission()` 只返回 `{ selected: false, actions: ['read'] }`。
  - `buildProfileGrants()` 合并键改为仅按 `actions`；删除 provider 分支、busy 只读校验和 `fields` 输出。
  - `profileGrant()` 不再要求/返回 `fields`。
- `web/src/main.tsx`
  - 删除“日历字段”下拉框、`setting.fields` 相关禁用逻辑、`selections` 中的 `fields`、授权详情的“字段”行。
- `src/web/i18n.ts`
  - 中英文删除 `calendarFields`、`full`、`busyOnly`、`fields` 键。
- `src/web/docs.ts`
  - 中英文“系统权限与授权”删除字段选择说明；
  - `unsupported_operation` 说明删除“仅忙碌字段”；
  - 权限范围说明改为只有容器和动作。

### CLI 与默认配置

- `src/cli/client-config.ts`
  - 默认 grants 删除 `fields: 'full'`。
- `src/cli/ui.ts`
  - `AuthShowHuman.grants` 删除 `fields`。
  - `authShow()` 删除 `Fields` 行。

## 非目标

- 不删除或改写历史版本文档中对 busy 的记录。
- 不为旧数据库、旧 `--auth-file`、旧客户端配置提供迁移或兼容层。
- 不改动提醒事项、Notes、原生 helper 的事件写入逻辑。

## 风险与说明

- **破坏性变更**：任何仍带 `fields` 的授权配置都会被 schema 拒绝；既有数据库中的 grants 不再视为受支持输入。维护者已确认当前无历史数据。
- 删除 `busy` 后，原本只能看到时间段的授权（若存在）语义变为完整内容；按“无历史数据”决策，不提供降级路径。
- `web/dist` 是构建产物，不手工修改；由 `npm run build:web` 重新生成。
