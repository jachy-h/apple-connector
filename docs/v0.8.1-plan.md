## 补充：未发布源码的直接接入

补齐当前机器具体 command/args/env、nanobot 配置文件位置、重启与只读验证步骤；明确凭证前置条件，不再只提供占位符或生成命令。本轮仍仅更新文档，不修改 host 配置。

## 本轮：npm link 与最小环境配置

按用户要求构建当前 v0.8.1，并通过 npm link 链接到当前 Node 安装的全局前缀。默认生成配置删除多余的 APPLE_CONNECTOR_STATE_DIR，仅显式自定义状态目录时保留；TOKEN_FILE 仍为当前凭证选择入口。同步文档，验证构建、配置生成和全局 CLI；不修改 host 配置或客户端授权。

## 本轮：README 收敛

README 只保留 nanobot 的可复制配置、凭证变量的必要性、可用工具和当前边界；将配对、源码安装与排障细节保留在独立配置指南。

## 本轮：配置 Agent 安装说明

新增极简的配置 Agent 文档，规定复用已有凭证、在缺少授权范围时向用户索取信息、合并 nanobot MCP 条目并使用只读工具验证。

## 本轮：全量默认授权

配置 Agent 在命令不存在时直接失败。增加 `containerIds: ["*"]` 的全容器授权语义，使默认安装无需用户提供容器 ID，并支持全量日历/提醒事项列举和授权校验。

## 本轮：客户端配置文件与统一本地数据目录

1. 将 `client create` 与 `client update` 的授权输入从命令行 JSON 改为必需的 `--config <绝对路径>`；配置文件分别使用 `{ name, grants }` 与 `{ id, name, grants }` 结构，并复用现有策略校验。
2. 默认状态目录改为 `~/apple-connector`，使 SQLite 数据库（包含审计记录）、服务 socket、令牌、日志和诊断日志位于同一受限目录；保留 `APPLE_CONNECTOR_STATE_DIR` 作为显式测试/迁移覆盖。
3. 更新中英文接入文档与配置 Agent 指南，展示在 `~/apple-connector` 创建配置文件的流程，不再在终端参数中拼接 JSON。
4. 以 TypeScript 编译、测试和 CLI 配置解析测试验证；仅在用户明确要求后删除原 `~/Library/Application Support/AppleConnector` 中已有数据。
