## 审计发现

- `package.json` 现为 `@jachy/apple-connector@0.8.3`，声明 public scoped publish、macOS/arm64、支持的 Node 范围和 canonical GitHub `repository`、`homepage`、`bugs` URL。它仍刻意不填 `license`，发布门禁会明确拒绝这种状态。
- tarball 仅包含运行所需的 `dist/src`、`dist/web`、arm64 helper、JXA 脚本、README 和用户文档。`release:verify` 禁止 `native/.build`、`native/` 和 `dist/tests`，并限制为最多 150 个文件和 25 MiB 压缩体积。
- 当前 native helper 已检查为 arm64 Mach-O；v0.8.3 明确仅支持 Apple Silicon，不将 x86_64 误表述为已支持。
- 当前工作树有大量未提交的 v0.8.1/v0.8.2 实现与文档改动；v0.8.3 实施必须保留它们，不能将其视为可清理的构建噪音。
- 默认 npm 缓存存在历史权限问题，本次审计通过独立临时 cache 完成；发布前需要确保真实 npm 认证环境可用。
