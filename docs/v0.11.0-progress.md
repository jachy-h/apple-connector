# Apple Connector v0.11.0 进度

更新日期：2026-11-16
对应计划：[v0.11.0-plan.md](./v0.11.0-plan.md)

## 当前状态

维护者已批准计划，并确认按推荐方案处理 `outcome_unknown`：仅 `executing` 阻止删除，`outcome_unknown` 允许删除并由审计保留不确定性。

源码、测试、文档和版本元数据已实现。定向存储/服务/Web 测试 38/38 通过；完整 `npm test` 为 114/115，唯一失败是 `agent-init` 在当前 SSH 会话中因 native helper 被系统结束、写入 stdin 触发 EPIPE 而无法启动服务，与 v0.10.0 已记录的环境限制一致。

2026-11-16 追加“权限页关闭/重新开启”调试补充：权限卡片可打开系统设置对应隐私面板，返回页面后自动重新检查，并新增“重新检查”按钮；不调用 `tccutil`、不重置 TCC。

工作树仍包含 v0.10.0 的未提交改动；本版本已叠加在其上，未回退或覆盖。

### 未完整执行 / 环境限制

- [ ] `agent-init` 在当前 SSH 会话中启动服务失败。复现时服务在 native helper 预热阶段因 helper 被系统结束而向 stdin 写入 `EPIPE`，进程在写出 socket 前退出。该现象与 v0.10.0 已记录的 native helper SIGKILL 环境限制一致，不是本版本源码回归；建议从本机 Terminal 复跑。
- [ ] `npm run release:verify` 因包含 `npm run check`，未在当前会话完整通过。
- [ ] 未运行完整 native opt-in 套件；本版本未改变 native helper 行为，仅更新版本字符串。
