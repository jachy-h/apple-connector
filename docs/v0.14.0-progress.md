# Apple Connector v0.14.0 进度

更新日期：2026-11-18
对应计划：[v0.14.0-plan.md](./v0.14.0-plan.md)

## 当前状态

维护者已批准按 `0.14.0` 实施。不可变授权、一次性 token、移除审批、`auth show`、迁移与页面改造已完成；构建与测试门禁通过。

## 已确认决策

- [x] 创建后的授权不可编辑，只能查看和删除。
- [x] 授权 ID 就是只显示一次的 token；同时写入本地 owner-only 文件，保证本地可按 token 找到授权。
- [x] 完全移除审批逻辑：无审批页、无 `prepared`、无 approve/reject，有写权限即直接执行。
- [x] 幂等键继续保留，写入仍要求显式 `--idempotency-key`。
- [x] 一个授权对应日历 N 个容器 + 提醒事项 M 个容器，每个容器分别勾选动作。
- [x] 不区分简单模式和高级模式。
- [x] 删除活跃授权时直接失效 token、删除本地文件和 operations，保留审计。
- [x] 新增只读 `auth show`。
- [x] 删除生产未使用的 `src/operations/reminders.ts`，测试迁移到 `AgentOperations`。
- [x] CLI `schemaVersion` 保持 `2`。
- [x] 版本号 `0.14.0`。

## 风险与后续

- 授权不可编辑，范围变更只能删除重建；页面已提示。
- token 只显示一次，但本地 `profiles/<uuid>.token` 仍保留；这是维护者明确要求的可恢复路径。
- 历史审计中的 `approval_required` / `approved` 仍可被 schema 解析，但新代码不再产生。
- 当前工作树包含 v0.10.0–v0.13.0 的未提交改动；本版本叠加在其上，未回退或覆盖。
