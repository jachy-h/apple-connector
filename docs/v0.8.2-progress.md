## 已发现问题

- v0.8.1 文档先展示需要 `APPLE_CONNECTOR_TOKEN_FILE` 的 host 配置，后解释如何生成 token，无法从空状态顺序执行。
- 默认策略仍以 nanobot 命名，且对全部 Reminders 赋予了 `create`，与“全部只读、Agents 可读写”不符。
- EventKit 已实现六种原生变更，但 agent 运输仅注册了提醒事项创建。

## 完成内容

- `apple-connector agent init` 在默认或自定义状态目录中先生成 `agent-client.json`，再配对并生成 0600 `agent.token`，最后输出绝对路径 MCP JSON。重复执行会验证并复用凭证，不新建客户端。
- 默认策略为 Calendar/Reminders `*` 只读，两个 `Agents` 名称范围单独获得写入 action，有效期为生成时起一年。
- 新增通用的持久化 agent 变更服务，在 prepare/commit 两次授权、保存幂等记录、审批状态、写后验证与不确定结果保护。
- MCP 新增 `calendar.create_event` / `update_event` / `delete_event` 及 `reminders.create` / `update` / `complete` / `delete`；保留旧的提醒事项 `changes.prepare` / `changes.commit`。
- `delete` 已加入策略 schema；Reminders 原生 helper 新增独立的完成并回读验证操作。
- README 和配置指南已移除当前 nanobot 专属步骤，改为通用 agent host 的合并说明；打包文件补充中英文 MCP 指南。
