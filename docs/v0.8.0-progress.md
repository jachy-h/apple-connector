## 当前状态

本地 stdio MCP 日常接入闭环已实现并进入自动验证；原生写入基线与 macOS 正式分发尚未完成。

- [x] 记录统一本地服务、辅助 CLI、工具契约、可靠性及 macOS 分发方向。

- [x] 完成本机 MCP/CLI 配对与服务生命周期：`mcp config --token-file` 输出绝对 stdio 配置，MCP 自动启动或复用本地服务。

## 本轮变更与验证

- 版本号更新为 0.8.0；README 增加安全凭证文件和配置生成说明。
- 客户端创建可用 `--credential-file <绝对路径>` 将一次性 token 写为 0600 文件；MCP 拒绝符号链接、非普通文件或组/其他用户可读的凭证文件。
- MCP stdio 入口不提供网络 MCP，启动或复用 Unix socket 本地服务，并使用 60 秒本地 RPC 超时。
- 未修改用户的 nanobot 配置；`mcp config` 只打印建议 JSON。
- 已通过 `npm test`（75 项）、`npm run check:jxa`（21 个固定 JXA 脚本）和 `git diff --check`；此次构建也成功完成 release Swift helper。
- 签名、公证、DMG/ZIP、Homebrew cask 与真实 Apple 写入验收仍未完成，原因是需要明确的发布身份、渠道和专用测试容器。
