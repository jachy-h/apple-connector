# Apple Connector v0.6.5 计划：日历事项增删改

更新日期：2026-09-07
进度记录：[v0.6.5-progress.md](./v0.6.5-progress.md)

## 目标

在本机管理网页中为指定日历提供新建、编辑和删除事项能力。

## 设计

- EventKit 日历读取结果携带稳定事件 ID；写入只接受该 ID，并在原生日历与非重复事项范围内验证目标。
- 新建、编辑、删除均经由持久化 Web 操作记录和浏览器生成的幂等 UUID；未知结果绝不自动重放。
- 原生 Helper 在同一次请求中检查权限、日历可写性、保存/删除并重新读取验证结果。
- 网页支持标题、起止时间、全天、地点和备注；写入成功后重新查询当前范围。
- 日历写入仅限认证的 loopback 管理网页，MCP 日历接口保持只读。

## 验收

1. 管理网页可新建普通或全天日程，并在成功后刷新列表。
2. 每个非重复日程可以编辑和删除，且写后结果由 EventKit 复核。
3. 无效时间范围、不可写日历、重复事项和不属于目标日历的 ID 会被拒绝。
4. 构建、TypeScript 测试、JXA 检查和差异检查通过。
