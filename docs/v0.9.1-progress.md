## 已核实

- 包限定 macOS arm64；Native deployment target 为 macOS 14；Node 范围见计划。
- `agent init` 当前调用链已经初始化本地状态、启动/复用 Application Core 和临时 Web。
- Web 当前要求手填容器 ID；EventKit reader 的空 scope 可以枚举已授权可见容器，适合管理页选择器。
- Web 仅在创建 profile 后知道 credential 文件路径；当前没有把该结果交回最初 Agent 的状态通道。
- credential 文件以 client ID 命名且为 owner-only；CLI 支持显式 `--credential-file`。
- 当前 Skill 没有 YAML frontmatter，也没有宿主中立的安装路径查询命令。
- npm 包当前未发布，正式安装文档尚不能对用户执行。
