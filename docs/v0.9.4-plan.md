# Apple Connector v0.9.4 计划：管理页面视觉重构、权限状态与 Agent 配置可见性

更新日期：2026-09-09
状态：待维护者批准
进度：[v0.9.4-progress.md](./v0.9.4-progress.md)

## 背景与目标

当前管理页面已具备权限申请、Agent profile 创建、审批和审计的基础功能，但视觉仍是早期的通用表单样式；权限页只在用户点击后以一条普通提示展示结果；已有 Agent profile 仅显示名称、启用状态和 policy 版本，无法查看实际授权范围。

v0.9.4 将以仓库根目录的 `design.md` 为唯一视觉依据，把管理页面重构为克制的黑白开发者平台界面，同时让权限状态与已有 Agent 配置在页面中可直接辨识。该版本不改变现有 loopback 会话、CSRF、RPC 白名单、授权策略或凭据边界。

## 实施范围

### 1. 依据 `design.md` 重构管理页面

- 将 `web/src/style.css` 的旧式蓝灰表单界面替换为设计稿定义的 token 化视觉：近白画布、`#171717` 墨色主操作、细灰分隔线、Geist/Inter 系统字体、等比 4px 间距、细边框加轻微叠层阴影。
- 重组 `web/src/main.tsx` 的页面壳层为品牌头部、单一主导航、清晰的页面标题/说明和卡片化内容区域；保留现有四个路由区段（权限、Agent 配置、审批、审计）、中英文切换、session 倒计时和失效禁用行为。
- 仅在页面头部/大面积装饰区域使用设计稿规定的蓝青紫粉橙网格渐变；不把该渐变挪作小型状态色。按钮、表格、表单、空状态和移动端布局均遵循 `design.md` 的圆角、字阶、间距与响应式策略。
- 维持所有现有操作的请求方法与参数：创建/撤销 profile、审批/拒绝操作、列出容器、权限申请、审计读取均不改变后端契约。

### 2. 权限状态的明确颜色标记与记录

- 页面初始加载时调用既有 `diagnostics.summary`，读取其 `systemPermissions` 中 Calendar 与 Reminders 的当前原生权限状态；不新增可供 Agent 调用的权限管理能力。
- 将 Calendar 与 Reminders 呈现为独立状态卡：已授权使用明显的成功色，未授权/被拒绝使用错误色，待确定/未探测使用警告或中性色；颜色之外始终提供文字状态与图标/标记，避免只靠颜色表达语义。
- 点击“请求权限”后，使用既有 `diagnostics.permissions.request` 的返回状态更新对应卡片，记录最近检查时间及该次操作的成功/错误结果于当前管理会话的页面状态。再次打开管理页时，以重新读取的原生状态作为权威结果，避免浏览器本地缓存伪造系统权限。
- 权限读取或申请失败时，保留可诊断的服务端错误文字，并以错误状态卡呈现“无法检查”；不将未知结果误标为已授权。

### 3. 显示已有 Agent 配置

- 将浏览器端 `Client`/`Grant` 数据类型从 `unknown[]` 收紧为与既有 `clients.list` 返回结构一致的只读展示模型，不改变数据库、策略 schema 或 `clients.list` 响应。
- 在 Agent 配置页为每个已有 profile 展示：名称、ID、启用/已撤销状态、policy 版本，以及每条 grant 的 provider、容器 ID/通配范围、允许动作、字段范围、审批模式和到期时间。
- 使用可扫描的 profile 卡片与授权摘要，而非只有四列表格；空 profile 或无授权时提供明确空状态。撤销按钮维持现有操作及 session 失效保护。
- 新建 profile 表单仍可创建当前支持的 Calendar/Reminders 授权；不在本版本加入编辑、复制、重新启用、token 显示或扩大授权范围等新行为。

### 4. 回归测试、版本与文档契约

- 增加可单测的权限状态归一化/语义映射与 grant 展示摘要工具，覆盖原生 `full_access`、拒绝、限制、未知/异常等状态不会被误显示为已授权，并覆盖 profile 的多条 grant 关键字段。
- 为管理页面请求序列补足测试：初次诊断读取、申请权限后的状态刷新，以及不改变 RPC 白名单和 agent transport 隔离。
- 将 package、lockfile、native helper `hello` 版本和 `release:verify` 版本断言同步至 v0.9.4，并更新 `docs/cli.md` 的当前版本描述。若构建/打包产物自动涵盖 Web 文件，则不手工维护生成文件。

## 验证标准

1. 管理页面的字体、颜色、间距、导航、表单、表格/卡片和响应式布局均与 `design.md` 的开发者平台视觉语言一致，且不损失现有中文默认和 English 切换。
2. 首次进入权限页会显示 Calendar 与 Reminders 的实际诊断状态；每项均有文字和明显语义色，不会把未知或检查失败显示为已授权。
3. 申请权限后卡片立即展示返回的最新状态、最近检查时间和操作结果；刷新/重新打开后以系统重新探测结果为准。
4. Agent 配置页能完整读取并显示既有 profile 的状态及每一条 grant 的 scope、actions、fields、approval、expiresAt，不泄露 token 或新增写入能力。
5. `npm test`、`npm run check:jxa`、`npm run release:verify` 和 `git diff --check` 通过。
6. 不覆盖、回退或混入工作区已有未提交改动；不发布 npm 包、不创建 Git tag 或 GitHub Release。
