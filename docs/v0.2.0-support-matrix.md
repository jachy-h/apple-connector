## 拒绝条件

- 目标容器不在有效授权中、授权已过期、客户端已撤销或计划绑定的策略版本已变化。
- Calendar 名称不唯一、稳定对象身份无法确认、重复事件/参与者/共享影响不明。
- Reminders 重复规则或清单共享状态无法可靠判定；现有对象形态不在已验证普通提醒范围内。
- Notes 文件夹或对象共享、锁定，或目标身份无法在授权文件夹内唯一确认。
- 原生写入返回丢失、超时、协议身份不匹配或写后回读失败时，结果记为 `outcome_unknown`，禁止自动重放。

## 诊断与恢复证据

M1 Reminders 诊断现在把创建、标题、备注、date-only、完成、核验和清理拆成独立原生调用。调用端在任何写入前持久化 UUID 日志，取得稳定 ID 后立即写回；日志权限为 0600，仅记录容器 ID、阶段、耗时和稳定 ID，不记录提醒正文或原始 native 错误。

恢复只接受日志中的 UUID，并优先使用稳定 ID。没有稳定 ID 时仅在原容器内合并精确原始标题和精确更新标题，按稳定 ID 去重；歧义不删除。删除后必须按稳定 ID 回读，结果区分 `not_found`、`removed_verified`、`ambiguous` 和 `outcome_unknown`。
