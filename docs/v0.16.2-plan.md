# Apple Connector v0.16.2 计划：修正提示词警告样式并收敛接入步骤

更新日期：2026-11-18

状态：已批准并实施完成（2026-11-18）

进度：[v0.16.2-progress.md](./v0.16.2-progress.md)

## 问题

1. “复制提示词”步骤里，“授权码只显示一次”和“含授权码提示词会留在聊天记录中”两段提示使用了 `.permission-error`，呈现为红底红字的错误样式，看起来像操作失败。
2. 页面生成的 Agent 提示词包含 7 个执行步骤，其中大量内容与本次初始化无关（文档入口、幂等 key、`outcome_unknown` 重试规则），并且与随包 Skill 重复。

## 结论

- 两段提示改为独立的警告样式，不再复用错误样式；真正的接口错误仍使用 `.permission-error`。
- 生成的提示词只保留本次接入需要的 3 步，固定规则交给随包 Skill，用一条 `skill path` 命令加载，不再在提示词里重复。

## 具体改动

### 1. 警告样式

- `web/src/style.css` 新增 `.permission-warning`：琥珀色背景 `#ffefcf`、边框 `#f5a623`、文字 `#ab570a`，与页面已有的分发提示保持一致。
- `web/src/main.tsx` 第 3 步中两处 `<p className="permission-error">` 改为 `.permission-warning`：
  - `authorizationIdWarning`（授权码只显示一次）
  - `agentPromptTokenWarning`（含授权码的提示词会留在聊天记录中）
- `permissionsError` 等真正的错误继续使用 `.permission-error`，样式和语义都不变。

### 2. 提示词收敛为 3 步

头部只保留凭据文件；授权名称放入标题，授权范围和过期时间不再写入提示词，改由 `auth show` 在需要时读取。含授权码版本继续保留一次性凭据的存储警告。

新的执行步骤（中英文同步）：

1. **加载随包 Skill**：`apple-connector skill path --json`。完整规则、命令和写入约束都在 Skill 中，不再在提示词里重复。
2. **完成绑定**：`apple-connector auth verify --agent '<你的名称>' --auth-file '<凭据文件>' --json`；成功后管理页立即显示“Agent 已绑定”。含授权码版本改用 `--auth '<授权码>'`。
3. **有界只读验证**：`apple-connector calendar list-calendars --auth-file '<凭据文件>' --json` 或 `apple-connector reminder list-lists --auth-file '<凭据文件>' --json`。

`auth show` 保留为非编号提示：需要查看授权名称、范围或过期时间时，运行 `apple-connector auth show --auth-file '<凭据文件>' --json`。初始化步骤本身不依赖它，范围可以等到实际使用时再查。

删除的内容：

- 头部的授权名称、授权范围和过期时间全部移除；提示词标题也一并移除，正文直接从接入说明开始。名称、范围和过期时间均可由按需运行的 `auth show --json` 提供。
- `open --section docs` 文档入口。
- `--idempotency-key`、`outcome_unknown` 等与初始化无关的写入规则；这些规则继续由 Skill 承载。

### 3. 保持一致的文档

为了避免提示词、Skill 和人类文档出现两套步骤数，同步以下文件中“粘贴提示词后 Agent 做什么”的列表：

- `README.md` / `README_zh.md` 的“面向 Agent”段落。
- `docs/getting-started.md` / `docs/getting-started_zh.md` 第 4 步说明。
- `docs/install-for-agent.md` / `docs/install-for-agent_zh.md` 的接入步骤。
- `docs/skill.md` 中描述提示词流程的一句话。
- `skill/SKILL.md` 的 Connect 步骤：调整为“加载 Skill → `auth verify` → 只读查询”，`auth show` 与文档入口改为非编号说明。写入、幂等、分页等完整规则保持不变。

### 4. 测试

- 更新 `tests/agent-prompt.test.ts`：
  - 断言提示词恰好包含 3 个编号步骤。
  - 断言第 2 步只执行 `auth verify --agent`，第 3 步包含一次只读查询。
  - 断言 `auth show` 作为按需提示保留在编号步骤之外。
  - 断言提示词没有标题或名称、范围、过期时间头部条目，正文直接从接入说明开始。
  - 断言不再出现 `open --section docs`、`idempotency-key`、`outcome_unknown`。
  - 保留凭据文件路径、含授权码版本的 `0600` 警告和不泄露授权码的断言。
- 现有 Skill 测试不受影响。

## 影响范围

- 只影响管理页第 3 步的展示、生成的提示词文本、对应测试和相关文档。
- 不改变授权、凭据、RPC、数据库或 CLI 命令契约。
- 旧提示词仍可继续使用；已创建的授权不受影响。
