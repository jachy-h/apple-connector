# Apple Connector v0.6.3 计划：修复日历查询与列表结果

更新日期：2026-09-07  
进度记录：[v0.6.3-progress.md](./v0.6.3-progress.md)

## 目标

修复管理网页按日历名称查询时把名称误传为 EventKit 日历 ID 而导致的失败，并将查询到的日程以可读、可翻页的列表展示。

## 设计

- Web 日历读取先以精确名称发现日历，要求唯一匹配，再把稳定 EventKit ID 传给事件读取器。
- 在日历查询页提供明确的“日历完全访问”授权入口；失败审计记录实际的受控错误码，而非笼统标作服务不可用。
- 保持对缺失和重名日历的明确拒绝，不猜测目标；审计记录解析后的 ID。
- Web 返回已解析日历元数据和分页事件，前端以日程卡片展示标题、时间、全天、地点与备注，并提供上一页/下一页。
- 同步版本号、增加服务层回归测试，完成 TypeScript、Web 构建及 JXA 检查。

## 验收

1. 输入唯一日历名称时，服务先解析 ID，再以该 ID 查询事件。
2. 不存在与重名日历得到明确错误，且不调用事件读取。
3. 页面不再输出原始 JSON，而以列表展示日程和分页控制。
4. 构建、测试、JXA 语法检查通过。
