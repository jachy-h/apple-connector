# Apple Connector v0.6.4 计划：修复提醒编辑与日历日期范围

更新日期：2026-09-07  
进度记录：[v0.6.4-progress.md](./v0.6.4-progress.md)

## 目标

修复管理网页提醒事项列表的“编辑”按钮无效问题，并简化日历查询为默认覆盖本月的日期范围。

## 设计

- 提醒事项列表中的编辑、完成、删除及分页控制均明确声明为 `type="button"`，避免被浏览器按提交按钮处理；编辑面板中的保存与取消同样明确其语义。
- 日历查询的起止控件改为日期而不是日期时间；初始值为本月第一日和最后一日。
- 前端将开始日期转换为本地当天零点，将结束日期转换为下一日零点作为服务端的排他上界，确保所选结束日全天被查询且不要求用户填写具体时间。

## 验收

1. 点击提醒事项“编辑”后显示可修改的编辑面板。
2. 日历页面无需填写时间，首次打开即显示本月首日与末日。
3. 日历请求包含所选结束日的全天事件。
4. Web 构建、TypeScript 测试和 JXA 检查通过。
