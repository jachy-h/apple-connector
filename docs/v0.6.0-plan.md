# Apple Connector v0.6.0 计划：提醒事项网页管理

更新日期：2026-09-07  
进度记录：[v0.6.0-progress.md](./v0.6.0-progress.md)

## 目标

优化本地管理页的提醒事项工作流：用户只输入清单的精确名称，页面自动解析唯一的 EventKit ID 并显示该 ID；查询结果以可读列表呈现；管理会话可编辑或删除单条普通提醒。

## 边界与安全契约

- 精确名称零匹配或重名时拒绝查询，绝不猜测目标；ID 不再要求用户复制填写，但会在页面只读显示。
- 编辑/删除仅限已查询到的同一清单内、稳定 EventKit ID 定位的普通提醒；重复提醒拒绝修改或删除。
- 每次变更使用浏览器生成的幂等 UUID。原生调用后失联或无法核验时标记为结果未知，不自动重放；成功或未知后清除正文等操作载荷。
- 变更仅开放给已认证的本地管理 Web 会话，不扩大 MCP 或客户端权限接口。
- 删除必须由用户在页面二次确认，并在 EventKit 删除后按稳定 ID 回读确认不存在。

## 实施与验收

1. 扩展 Swift EventKit helper 与 TypeScript provider，固定实现单条更新、删除及回读核验。
2. 扩展 Web 操作持久化和审计，使更新、删除与新增具有同等幂等/未知结果语义。
3. 将提醒事项页面改为名称解析、ID 展示、卡片列表、内联编辑和确认删除，并改善响应式布局。
4. 运行 TypeScript 回归、Web 构建和 Swift release 构建；真实变更另限专用测试清单进行核验，不能用编译成功替代。
