# Apple Connector v0.9.3 计划：管理页面中文默认与中英文切换

更新日期：2026-09-09
状态：已实施并验证
进度：[v0.9.3-progress.md](./v0.9.3-progress.md)

## 背景与目标

当前本地管理页面的所有静态界面文案均为英文。v0.9.3 将把页面默认界面语言设为简体中文，并提供明确、可访问的中英文切换控件，方便用户随时切换。默认行为不依赖浏览器语言或 IP；首次打开始终显示中文，避免中文用户被意外切换为英文。

## 实施范围

### 1. 客户端本地化结构

- 将 `web/src/main.tsx` 中的静态可见文案收敛到中英文词典，覆盖加载、会话状态、导航、权限、Agent profile、审批、审计、按钮、表头、表单字段、空状态与成功提示。
- 动态数据（容器名、profile 名称、操作 ID、服务端返回的错误）保持原样；不翻译服务端错误，避免改变诊断语义。
- 时间继续使用浏览器的本地格式；切换语言时使用 `zh-CN` / `en-US` 显式格式化管理会话、审批和审计时间，以使日期展示与所选界面语言一致。

### 2. 默认语言与切换

- 初始语言固定为简体中文（`zh-CN`）。
- 在页面 header 提供 `中文 / English` 双按钮或等价的单一语言选择控件，具备清晰的当前态、键盘可操作性和适当的 `aria-label`。
- 用户选择保存到浏览器 `localStorage`；同一浏览器后续管理会话沿用选择。不存在、无效或不可读的存储值时安全回退为中文。
- 切换只影响展示文案和日期格式，不重启 session、不发起管理 API 请求，也不修改服务端、授权、profile 或审计数据。

### 3. 回归测试与版本契约

- 抽出可单测的语言解析/词典工具，覆盖“缺少或非法偏好值默认中文”、合法中文和英文偏好、关键中英文文案及 locale 格式选择。
- 更新 v0.9.3 的 package/lockfile/helper handshake/release verifier 版本断言，并视现有发布文件清单决定是否需要加入新模块（若模块由 `dist/src` 自动包含，则不额外维护清单）。
- 更新 `docs/cli.md` 中产品版本描述；不改变 CLI JSON schema 或 API 行为。

## 验证标准

1. 新管理会话首次显示简体中文，不依据浏览器环境自动改为英文。
2. 用户可以在中文与 English 间切换；控件当前状态清晰、可使用键盘操作，且选择在同一浏览器后续会话中保留。
3. 切换覆盖所有客户端静态可见文案与前端生成的消息；服务端动态错误与用户数据不被篡改。
4. 语言切换不触发 RPC，也不会影响当前页面、session、授权或数据。
5. `npm test`、`npm run check:jxa`、`npm run release:verify` 和 `git diff --check` 通过。
6. 不覆盖或回退工作区已有的未提交改动；不发布 npm 包、不创建 Git tag 或 Release。
