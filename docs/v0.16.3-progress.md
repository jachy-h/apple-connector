# Apple Connector v0.16.3 进度

更新日期：2026-11-19

对应计划：[v0.16.3-plan.md](./v0.16.3-plan.md)

## 当前状态

已批准、实施并完成验证。版本号 `0.16.3`；数据库结构不变。

## 已实施

### CLI

- [x] 新增 `--auth-key <key>`，解析 `<state dir>/profiles/<key>.token`；key 限制为安全文件名，拒绝路径分隔符、`.`、`..` 和空白。
- [x] 未知 key 返回 `Unknown authorization key`，错误信息不包含解析后的文件路径。
- [x] 保持认证优先级：`--auth-file` → `--auth` / `APPLE_CONNECTOR_AUTH` → `--auth-key` / `--profile` → `--credential-file` → `profiles/default.token`。
- [x] `profiles/` 路径解析集中到 `clientTokenFile()` / `readClientTokenByKey()`。

### 管理页与提示词

- [x] `clients.create` 返回 `credentialKey`（`client.id`），继续保留 `credentialFile`。
- [x] 推荐提示词只包含授权 key，命令改用 `--auth-key`，不再包含 token 文件路径。
- [x] 提示词明确要求 Agent 不要读取、复制、扫描或打印 profile 目录中的 token 文件。
- [x] 中英文 i18n 的“内部记录编号”改为“授权 key / Authorization key”，并同步接入说明。
- [x] 第 4 步等待绑定示例改用 `--auth-key <key>`。
- [x] 含授权码的备用提示词继续使用 `--auth '<token>'`。

### 文档、帮助与 Skill

- [x] `src/cli/ui.ts` 的总览、options、usage 和 examples。
- [x] `src/web/docs.ts` 的中英文快速命令、业务命令和接入说明。
- [x] `skill/SKILL.md` 的授权 key、Connect 步骤和兼容说明。
- [x] `docs/cli.md`、`docs/skill.md`、getting-started、install-for-agent、README 中英文同步。
