# Apple Connector v0.7.0 计划：暂时屏蔽备忘录功能

更新日期：2026-09-07
进度记录：[v0.7.0-progress.md](./v0.7.0-progress.md)

## 目标与范围

v0.7.0 暂时不提供 Apple Notes（备忘录）功能。外部 CLI 调用、管理网页及服务入口均不可使用备忘录查询或写入，也不通过诊断、容器发现或历史操作执行路径间接访问 Notes。

此前讨论的 Notes Swift helper、正文原样返回、搜索优化及性能测量全部延期。本版本不运行涉及真实备忘录的诊断。

## 实施方案

### 1. 在服务层统一禁用 Notes

- 建立明确的 Notes 禁用状态，使能力声明不再将 Notes 标记为可用，不再声明可调用的 Notes 操作。
- Notes 文件夹列举、搜索、详情和创建等请求在进入 provider、JXA 或原生进程前返回稳定的 `unsupported_operation` 错误，说明本版本暂不支持备忘录。
- 检查历史 Notes 操作的批准与执行入口，确保旧计划不能触发原生访问；保留历史状态和审计的只读查询。
- 保留必要的内部类型与旧数据解析兼容性，避免禁用 Notes 导致已有客户端、操作记录或审计加载失败。

### 2. CLI 和诊断入口

- 不新增或开放 `notes` CLI 命令；明确拒绝 Notes 功能调用。
- CLI 容器发现仅访问仍支持的数据源，移除 Notes 文件夹枚举；帮助文本同步更新。
- 新建客户端或新增 Notes 授权时明确拒绝；已有 Notes 授权不产生访问能力。涉及多数据源的授权更新保留其他有效授权，明确处理旧 Notes 授权，避免静默扩大或删除其他权限。
- 排查容器发现、只读摘要、探针及诊断工具中的 Notes 分支，确保禁用期间不启动 Notes 自动化、不读取内容、不请求 Notes 权限、不执行 Notes CRUD。

### 3. 网页和其他既有对外入口

- 隐藏管理网页中的 Notes 应用页、Notes 授权选项、文件夹发现结果和 Notes 读取诊断选项。
- 直接调用旧 Web/RPC 方法仍由服务端拒绝，不能仅依靠隐藏页面屏蔽功能。
- 本版本不开展 MCP 功能设计或扩展；仅撤下现有 Notes 工具注册，确保既有入口不会继续暴露已禁用功能。
- 历史审计、历史操作和已有授权可以显示 Notes 标识及禁用状态，这些展示不得触发原生查询。

### 4. 内部代码与文档

- 可保留 Notes provider 和固定脚本供后续版本恢复，但从运行时入口断开；检查打包脚本和诊断命令，避免将旧 Notes 脚本作为仍受支持的可执行功能暴露。
- 不删除用户备忘录、已有授权记录、审计或历史操作数据。
- 更新 README、CLI 帮助和当前能力说明，统一注明 v0.7.0 暂不支持 Notes；历史版本文档保留原有事实。
- 更新版本信息至 0.7.0。

## 实施顺序

1. 清点 Notes 对外入口、间接诊断路径及历史数据兼容点。
2. 实现服务层禁用状态与执行前拦截，关闭所有原生 Notes 调用路径。
3. 收敛 CLI、管理网页、授权配置和既有工具注册。
4. 更新当前文档、版本信息并完成回归验证。

## 验收标准

1. CLI 不提供可用的 Notes 功能，容器发现不会读取 Notes 文件夹。
2. 旧 Notes RPC/Web 请求及旧计划执行均明确失败，且测试证明 Notes reader、writer、JXA 执行器未被调用。
3. 网页不显示可操作的 Notes 功能；能力声明和既有工具注册不宣称 Notes 可用。
4. 新增 Notes 授权被拒绝；旧 Notes 授权无法访问 Notes，其他数据源授权和历史记录仍可正常读取与管理。
5. 日历、提醒事项及其 CLI、网页和服务行为不受影响。
6. 自动化测试覆盖直接与间接禁用路径及旧数据兼容；构建、相关回归测试、JXA 语法检查和差异检查通过。验收不运行真实 Notes CRUD。

## 后续版本再讨论

- CLI Notes 只读命令与完整原文返回契约。
- Swift helper / ScriptingBridge 接入及独立进程隔离。
- 标题搜索、全文搜索、长正文传输与性能测量。

上述事项不属于 v0.7.0 的开发范围。
