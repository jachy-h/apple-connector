## 注意

- 旧绝对路径（如 Agent 配置里的 `~/apple-connector/profiles/<id>.token`）在迁移后失效；使用 `--profile <id>` 或新的 `~/.apple-connector/profiles/<id>.token`。
- 迁移不保留旧目录副本；如需回滚，必须在迁移前自行备份。
- 迁移后服务未自动启动；需要时运行 `apple-connector start` 或 `apple-connector open`。
