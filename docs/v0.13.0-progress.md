# Apple Connector v0.13.0 进度

更新日期：2026-11-17
对应计划：[v0.13.0-plan.md](./v0.13.0-plan.md)

## 当前状态

维护者已批准按 `0.13.0` 实施。CLI help/version、picocolors 展示层、详细使用文档、测试、版本元数据和构建产物已完成。

工作树仍包含 v0.10.0、v0.11.0、v0.12.0 的未提交改动；本版本叠加在其上，未回退或覆盖。
